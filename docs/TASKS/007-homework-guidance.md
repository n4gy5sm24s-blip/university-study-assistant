# Task 007：基于课程资料的作业辅导

> 状态：已完成

## Goal

让学生针对作业题选择帮助强度，并得到基于当前课程资料、有引用、符合学习诚信边界的辅导。

## Scope

### Touch

- 提示、分步讲解、答案检查三种模式；
- 学生已有尝试输入；
- 作业题检索和课程引用；
- 生成模型任务指令与本地降级；
- API、最小界面和自动测试。

### Do Not Touch

- 自动登录或提交作业；
- 生成冒充学生的整份作业；
- 图片题目和 OCR；
- 学习状态和错题记录。

## Acceptance Criteria

1. 默认模式只给方向、相关概念和第一步。
2. 分步模式给出可执行的思考步骤和课程依据。
3. 检查模式必须提供学生自己的尝试。
4. 三种模式都只使用指定课程检索结果并返回 citations。
5. 资料不足时不凭空给出作业答案。
6. 未配置或模型失败时仍提供本地依据式辅导。
7. 自动测试覆盖三种模式的关键边界。
