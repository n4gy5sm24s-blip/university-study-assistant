# Task 030：一键启动 Chrome 网页版

## 目标

为不熟悉终端的用户提供桌面快捷方式，自动启动本机 FastAPI 后台并在 Google Chrome 打开网页版作业机。

## 行为

- 固定使用 `127.0.0.1:8000`；
- 继续读取项目 `data/study_assistant.db` 和 `data/uploads` 中的原课程记录；
- 已有健康服务时不重复启动；
- 后台以隐藏窗口运行；
- 优先使用 Google Chrome，找不到 Chrome 时使用系统默认浏览器；
- 启动失败时显示可理解的 Windows 提示。

## 验收

1. 桌面出现 `Open Coursework AI` 快捷方式；
2. 双击后无需终端即可打开网页版；
3. 网页显示原来的课程记录；
4. 重复双击不会产生多个监听 `8000` 端口的后台。
