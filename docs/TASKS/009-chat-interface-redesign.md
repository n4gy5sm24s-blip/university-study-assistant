# Task 009：纯黑聊天界面与作业优先工作流

> 状态：已完成

## Goal

把功能测试式页面重构为以作业生成为主、接近现代 AI 对话产品的专业工作区。

## Acceptance Criteria

1. 整体为纯黑深色视觉，层级清楚且适配手机。
2. 左侧栏负责课程选择和新建课程。
3. 中央区域显示用户与助手的消息流。
4. 底部输入框是主要入口，默认模式为“写作业”。
5. 支持写作业、随时问答和检查答案三种对话模式。
6. 资料管理和紧急复习通过独立弹层进入，不占据主聊天流。
7. 作业草稿保留课程引用；未配置模型时如实说明只能提供依据框架。
