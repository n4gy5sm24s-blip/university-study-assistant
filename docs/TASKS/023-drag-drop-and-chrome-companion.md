# Task 023：拖放图片与 Chrome Companion

## 目标

减少题目输入摩擦，并让用户在明确授权后把当前 Chrome 作业页面交给本地作业机处理。

## 验收

- 聊天框支持拖入 JPG、PNG、WebP，以及直接粘贴剪贴板图片。
- 从网页拖入图片时尝试读取；受跨域限制时给出复制图片后粘贴的替代路径。
- Chrome 扩展只使用 `activeTab`，不申请全站永久读取权限。
- 只有用户点击扩展按钮时才读取当前标签页，优先读取选中文字。
- 用户在扩展中选择课程，答案继续经过本地 RAG 和课程引用流程。
- 扩展可以复制草稿，但不自动填写或提交学校/Google 表单。
