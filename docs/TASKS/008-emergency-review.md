# Task 008：紧急复习计划

> 状态：已完成

## Goal

根据考试范围、剩余时间和学生自报薄弱点，从当前课程资料生成可执行的保底复习计划和闭卷自测。

## Scope

### Touch

- 考试范围、可用小时数和薄弱点输入；
- 课程主题提取与薄弱点优先；
- 分钟级复习块、自测和最后回顾；
- 计划依据和限制说明；
- API、界面和自动测试。

### Do Not Touch

- 猜测教师未公布的考试权重；
- 日历提醒；
- 自动评分和错题持久化；
- 图片、PDF 和 OCR。

## Acceptance Criteria

1. 计划总分钟数等于用户提供的可用时间。
2. 用户自报薄弱点优先排列。
3. 每个资料主题都有来源引用和一条闭卷自测题。
4. 最后约 30% 时间用于自测和回顾。
5. 找不到指定范围或课程没有资料时返回 `no_evidence`。
6. 明确说明计划依据资料覆盖，不代表真实考试权重。
7. 不读取其他课程的资料。

## Verification

- 测试覆盖时间分配、薄弱点优先、未知范围、空课程和课程隔离；
- 完整单元测试共 33 项，全部通过；
- 原有 20 个固定 Evals 继续全部通过；
- 上传、问答、作业辅导、复习计划和删除的集成检查通过。
