# Task 012：PPTX 课件上传与索引

> 状态：已完成

## Goal

让学生直接上传老师提供的 PPTX 课件，不需要自己转换成 Markdown 或逐页截图。

## Acceptance Criteria

1. 资料库接受 `.pptx`、`.md` 和 `.txt`。
2. PPTX 最大 25MB，损坏或无文字的文件给出明确错误。
3. 自动提取每张幻灯片的标题和正文。
4. 按幻灯片编号建立检索章节，例如“第 12 张：心理安全”。
5. 检索、作业引用和考前急救保留原始 PPTX 文件名与幻灯片编号。
6. 原始 PPTX 保存在当前课程的本地资料目录中。

## Verification

- 使用程序生成的真实 PPTX 验证上传、解析、保存与检索。
- 40 项单元测试通过。
- 固定 Evals 20/20 通过。
- 端到端检查通过。
