# Task 010：资料缺口检测与补拍建议

> 状态：已完成

## Goal

在生成作业前评估现有课程资料能否覆盖题目要求，并把缺失证据转换成学生可以执行的教材补拍建议。

## Acceptance Criteria

1. 识别题目需要的定义、机制、比较、案例、建议、评价或公式数据。
2. 返回资料充分度、等级、已有依据和缺少内容。
3. 没有命中资料时，不生成无依据答案，并指出应查找的教材小节。
4. 部分命中时仍可生成初稿，同时标记薄弱部分。
5. 补拍建议包含内容类型、建议页数和拍摄完整性要求。
6. 写作业界面以独立卡片显示资料缺口。

## Verification

- 增加无依据和部分依据场景的单元测试。
- 前端 JavaScript 语法检查通过。
- Git 差异检查通过。
