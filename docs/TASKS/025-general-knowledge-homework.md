# Task 025：无课程资料时的通用知识作业模式

## 目标

允许用户在明确开启“通用知识”后，对不依赖课程资料的作业题生成草稿，同时清楚区分课程依据与模型通用知识。

## 范围

- 作业请求增加 `allow_general_knowledge`；
- 没有检索结果且用户允许时，由已配置模型生成无引用草稿；
- 回答明确标注未使用课程资料；
- 前端增加可见开关并正确展示生成来源；
- 保持教材问答模式的严格资料约束不变。

## 验收标准

1. 未开启通用知识时，缺少课程资料仍然拒绝生成；
2. 开启且模型可用时，返回 `general_knowledge` 状态、空引用和明确提示；
3. 开启但模型不可用时，提示先配置模型；
4. 有课程资料时仍优先使用资料并返回引用；
5. 前端不会把通用知识回答标成“已使用课程资料”。
