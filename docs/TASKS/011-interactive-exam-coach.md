# Task 011：互动式考前急救

> 状态：已完成

## Goal

把一次性复习计划改成由软件主动带领的复习流程：讲解一个知识点、要求闭卷回答、依据课程资料纠错，再进入下一个知识点。

## Acceptance Criteria

1. 用户设置考试范围、可用时间和薄弱点后直接开始复习。
2. 每轮只展示一个主题、课程依据和一道闭卷题。
3. 用户提交回答后，系统依据课程资料反馈正确点、遗漏与参考依据。
4. 完成纠错后进入下一个主题，并显示当前进度。
5. 所有主题完成后可以再复习一轮。
6. 未配置生成模型时仍提供基于原文的纠错依据。

## Verification

- 互动纠错与未知主题测试通过。
- 全部单元测试、Evals 和端到端检查通过。
- 手机宽度浏览器人工验收通过。
