# Decision 002：以作业生成为主的聊天式产品

## Status

Accepted by product owner on 2026-10-17.

## Decision

- 产品的首要任务调整为：根据用户上传的课程资料，帮助生成完整、可编辑、有引用的作业草稿。
- 教材问答、答案检查和紧急复习作为同一聊天工作区中的辅助模式。
- 默认交互模式从“提示第一步”改为“写作业”。
- 界面采用纯黑、专业、低干扰的聊天式布局：课程侧栏、中央对话、底部输入框。
- 系统可以生成完整草稿，但不自动登录课程系统、不自动提交、不伪造资料依据，也不声称草稿已经由学生本人独立完成。

## Consequences

- Homework Service 增加 `draft` 模式并成为 API 默认值。
- 旧的多表单功能页被统一聊天入口替代。
- 用户仍可选择问答、检查答案和复习计划。
