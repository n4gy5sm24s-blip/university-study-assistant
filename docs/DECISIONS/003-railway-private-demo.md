# Decision 003：Railway 仅用于单用户私有演示

## 状态

已接受，2026-10-28。

## 决定

- Railway 是当前首选托管平台，使用 GitHub 自动部署 FastAPI。
- SQLite 与上传资料放在 Railway Volume 中；未挂载 Volume 时不承诺数据持久化。
- OpenAI API Key 只通过 Railway 环境变量注入，线上默认关闭网页端模型配置写入。
- 在身份认证和用户级数据隔离完成之前，部署版本只视为单用户私有演示，不作为面向公众的正式产品。

## 原因

当前系统的数据模型是单用户设计，所有课程、资料、作业和学习记录共用一个 SQLite 数据库。直接公开会造成数据越权、密钥配置被修改和用户资料混用。

## 后果

- 首次 Railway 部署需要配置 Volume 和环境变量；
- 公开域名只能用于受控演示；
- 正式开放给其他学生前，必须增加认证、授权和用户数据隔离。
