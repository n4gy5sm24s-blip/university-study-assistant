# 大学生学习助手

这是一个资料可插拔的大学生学习平台。每个用户可以创建自己的课程空间、上传有权使用的教材和课程资料，并使用教材问答、作业辅导、重大考试前紧急复习和自由答疑功能。

当前阶段：**Build — Task 004 已完成**

## 暂定原则

- 帮助学习，不代替学生完成和提交作业。
- 基于课程资料回答时显示来源。
- 不知道时明确说明，不编造答案或引用。
- 先完成一个课程空间的一条学习闭环，再扩展格式和能力。
- 每次只开发一个能够检查的小功能。

## 项目推进顺序

1. 确认第一版的用户、场景和边界。
2. 完成 docs/SPEC.md。
3. 设计最小端到端流程和 docs/ARCH.md。
4. 写安全与质量规则。
5. 定义第一个可验证任务。
6. 在本地实现和测试。
7. 学习 Git，把项目保存到 GitHub。

## 当前要做的事

目前已经支持：

- 创建、查看和删除课程空间；
- 向课程上传 Markdown 或 TXT 资料；
- 检查空文件、错误格式和重复内容；
- 查看处理状态并彻底删除资料。
- 自动把资料切分成带章节和顺序的片段；
- 在指定课程内搜索资料，并显示命中的原文和来源。
- 使用自然问题查找课程依据，并返回文件、章节和片段级引用；
- 资料不足时明确提示，不生成没有依据的答案。

安装依赖后可以运行：

    python -m pip install -r requirements.txt
    python -m unittest discover -s tests
    python -m uvicorn app.main:app --reload

然后访问 http://127.0.0.1:8000。
