# 大学生学习助手

这是一个资料可插拔的大学生学习平台。每个用户可以创建自己的课程空间、上传有权使用的教材和课程资料，并使用教材问答、作业辅导、重大考试前紧急复习和自由答疑功能。

当前阶段：**Build — Task 006 已完成**

## 暂定原则

- 帮助学习，不代替学生完成和提交作业。
- 基于课程资料回答时显示来源。
- 不知道时明确说明，不编造答案或引用。
- 先完成一个课程空间的一条学习闭环，再扩展格式和能力。
- 每次只开发一个能够检查的小功能。

## 项目推进顺序

1. 确认第一版的用户、场景和边界。
2. 完成 docs/SPEC.md。
3. 设计最小端到端流程和 docs/ARCH.md。
4. 写安全与质量规则。
5. 定义第一个可验证任务。
6. 在本地实现和测试。
7. 学习 Git，把项目保存到 GitHub。

## 当前要做的事

目前已经支持：

- 创建、查看和删除课程空间；
- 向课程上传 Markdown 或 TXT 资料；
- 检查空文件、错误格式和重复内容；
- 查看处理状态并彻底删除资料。
- 自动把资料切分成带章节和顺序的片段；
- 在指定课程内搜索资料，并显示命中的原文和来源。
- 使用自然问题查找课程依据，并返回文件、章节和片段级引用；
- 资料不足时明确提示，不生成没有依据的答案。
- 可选接入 OpenAI Responses API，把检索原文整理成带引用的中文讲解；
- 模型未配置或调用失败时自动退回本地原文依据模式。

安装依赖后可以运行：

    python -m pip install -r requirements.txt
    python -m unittest discover -s tests
    python -m app.evals
    python -m uvicorn app.main:app --reload

然后访问 http://127.0.0.1:8000。

### 可选：启用生成模型

1. 把 `.env.example` 复制为 `.env`；
2. 在 `.env` 中填写自己的 `OPENAI_API_KEY` 和账户可用的 `OPENAI_MODEL`；
3. 重新启动应用。

`.env` 已被 Git 忽略，不能把真实密钥提交到仓库。启用模型后，每次只发送当前问题和最多三个相关资料片段。未配置时不影响课程、资料、检索和引用功能。

固定 Evals 目前包含 20 个自制问题，用于检查检索召回、无依据拒答和引用正确性。基线结果见 `evals/BASELINE.md`。

下一步可以实现作业辅导模式，或先进行本地 MVP 人工验收。真实教材仍不需要提供，自动测试继续使用自制资料。
