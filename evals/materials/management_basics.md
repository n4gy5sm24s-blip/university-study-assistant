# 机会成本

机会成本是为了选择一个方案而放弃的其他方案中价值最高的那个。管理者比较方案时，应把被放弃的最佳替代选择纳入判断。

# 竞争优势

竞争优势是企业相对于竞争对手创造并保持更高顾客价值的能力。它可能来自成本领先、差异化能力或难以模仿的资源。

# 波特五力

波特五力用于分析行业竞争结构，包括现有竞争者、潜在进入者、替代品、供应商议价能力和购买者议价能力。

# 目标管理

目标管理要求管理者和员工共同确定清晰目标，并用可观察的结果检查完成情况。目标需要具体、可衡量并与组织方向一致。

# 心理安全

心理安全是团队成员相信自己可以提出问题、承认错误和表达不同意见，而不会因此受到羞辱或惩罚的共同信念。

# 组织文化

组织文化是成员共同接受的价值观、规范和行为方式。文化会影响成员如何判断问题、合作以及做出日常决定。
