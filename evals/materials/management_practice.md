# 授权管理

授权管理是把完成任务所需的职责和相应权限交给员工，同时保留必要的目标、资源支持和结果反馈。

# 变革阻力

变革阻力可能来自不确定感、既有利益受影响、习惯被打破以及对管理层缺乏信任。沟通和参与可以减少部分阻力。

# 激励因素

激励因素是能够影响个体努力方向、强度和持续时间的条件。不同员工重视的奖励、成长机会和工作意义可能不同。

# 团队规范

团队规范是成员对可接受行为形成的共同预期。规范会影响沟通方式、工作节奏、责任承担和冲突处理。

# 决策偏差

决策偏差是判断系统性偏离理性标准的现象。确认偏差会让人更重视支持原有观点的信息，忽略相反证据。

# 利益相关者

利益相关者是会影响组织或受到组织决策影响的个人和群体，例如员工、顾客、供应商、投资者和社区。
